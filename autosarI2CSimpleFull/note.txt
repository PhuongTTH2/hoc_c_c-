1. Registers cần config CHO TỪNG CHANNEL:

1. SSRmn    - Serial Status Register          (Clear flags)
2. SIRmn    - Serial Flag Clear Trigger       (Clear error flags)
3. SMRmn    - Serial Mode Register            (Set I2C mode)
4. SCRmn    - Serial Communication Run Setting (MOST IMPORTANT!)
5. SDRmn    - Serial Data Register            (Set baud rate divider)

2. Unit-level registers cần config:

6. SPSm     - Serial Clock Selection Register (Clock source)
7. SOm      - Serial Output Register          (Pin output level)
8. SOEm     - Serial Output Enable Register   (Enable pin output)
9. SSm/STm  - Start/Stop Registers            (Control channel)
10. PER0/PER2 - Peripheral Enable             (Enable clock)

3. GPIO config cho mỗi channel:

11. POMxx   - Port Output Mode                (Set to open-drain)
12. PMxx    - Port Mode                       (Input/Output)
13. PUxx    - Pull-up Resistor                (Enable pull-up)
14. PMCxx   - Port Mode Control               (Digital I/O mode)

A. SMRmn (Serial Mode Register):

CKS=0   (Use CKm0)
CCS=0   (Use divided FMCK)
STS=0   (Software trigger)
SIS=0   (Normal edge detection)
MD2,1=1,0 (Simplified I2C mode)
MD0=0   (Transfer end interrupt)

B. SCRmn (Serial Communication Run Setting Register) - QUAN TRỌNG NHẤT:

TXEmn=1     (Transmit enable)
RXEmn=1     (Receive enable)
DAPmn=0     (Not used in I2C)
CKPmn=0     (Not used in I2C)
EOCmn=0     (Error interrupt enabled)
PTCmn1,0=00 (No parity for I2C)
DIRmn=0     (MSB first for I2C)
SLCmn1,0=01 (1 stop bit for I2C)
DLSmn3-0=0111 (8-bit data for I2C)
Bit 2=1     (Required fixed value)
Bits 3,6,11=0 (Required fixed value)

| Thứ tự | Register  | Vai trò                                     |
| ------ | --------- | ------------------------------------------- |
| 1      | **SSRmn** | Trạng thái + lỗi (ACK/NACK nằm ở đây)       |

| 5      | **SDRmn** | Baud rate divider (tạo SCL)                 |


1. SSRmn – Serial Status Register (READ-ONLY)
| Bit | Tên     | Ý nghĩa                       |
| --- | ------- | ----------------------------- |
| 0   | OVF     | Overflow error                |
| 1   | **PEF** | **ACK/NACK error (NACK = 1)** |
| 2   | FEF     | Framing error                 |
| 6   | BFF     | Buffer full                   |
| 8   | TSF     | Transfer in progress          |

2. SIRmn – Serial Flag Clear Trigger Register (WRITE-ONLY)

| Bit | Tên  | Clear              |
| --- | ---- | ------------------ |
| 0   | OVCT | Overflow           |
| 1   | PECT | Parity / ACK error |
| 2   | FECT | Framing            |
0x0007 = 0000 0000 0000 0111
         │││└─ FECT = 1
         ││└── PECT = 1
         │└─── OVCT = 1

3. SMRmn – Serial Mode Register (MODE SELECT)

| Bit | Tên | Giá trị cho I²C      |
| --- | --- | -------------------- |
| 14  | MD2 | 1                    |
| 13  | MD1 | 0                    |
| 12  | MD0 | 0                    |
| 1   | CCS | 0 (internal clock)   |
| 0   | CKS | 0 (CKm0)             |
| 9   | SIS | 0                    |
| 8   | STS | 0 (software trigger) |

0x4000 = 0100 0000 0000 0000
         │└──────── MD2 = 1
         └───────── MD1,MD0 = 0 → Simplified I2C


4. SCRmn – Serial Communication Run Setting

| Trường    | Giá trị          |
| --------- | ---------------- |
| TXEmn     | 1                |
| RXEmn     | 1                |
| DAPmn     | 0                |
| CKPmn     | 0                |
| EOCmn     | 0                |
| PTCmn     | 00               |
| DIRmn     | 0 (MSB first)    |
| SLCmn     | 01 (1 stop bit)  |
| DLSmn     | **0111 (8-bit)** |
| Bit2      | **1 (FIXED)**    |
| Bit3,6,11 | 0                |
